# Panduan Penggunaan SALATIFY

## 1. Instalasi
- Pastikan file `salatify-1.0.0-debug.apk` tersedia.
- Aktifkan opsi "Instal aplikasi dari sumber tidak dikenal" di pengaturan Android.
- Buka file APK dan pilih Instal.
- Berikan izin lokasi dan notifikasi saat diminta.

## 2. Pertama Kali Menggunakan
- Layar pembuka (splash) akan muncul lalu arahkan ke halaman Masuk.
- Pilih **Daftar** untuk membuat akun baru (username, email, password).
- Masuk dengan username/email dan password.
- Alternatif: pilih **Masuk sebagai Tamu** untuk mencoba fitur dasar tanpa akun.

## 3. Dashboard
- Tampilkan salam sesuai waktu, tanggal Masehi, jam digital, dan jadwal sholat hari ini.
- Countdown menampilkan waktu tersisa ke sholat berikutnya.
- Tombol akses cepat: Jadwal Sholat, Arah Kiblat, Dzikir, Kumpulan Doa, Al-Qur'an, Pengaturan.

## 4. Jadwal Sholat
- Lihat jadwal Subuh, Dzuhur, Ashar, Maghrib, Isya.
- Data diambil berdasarkan lokasi (latitude/longitude) dan metode perhitungan.
- Tekan "Perbarui Jadwal" untuk mengambil data terbaru dari API.
- Jika tidak ada jaringan, data tersimpan sebelumnya ditampilkan (offline).

## 5. Pengingat Sholat
- Buka Pengaturan > Pengaturan Notifikasi.
- Aktifkan pengingat dan pilih waktu peringatan (tepat waktu, 5/10/15 menit sebelumnya).
- Nyalakan suara dan/atau getaran sesuai keinginan.

## 6. Arah Kiblat
- Pastikan GPS dan sensor kompas aktif.
- Arahkan perangkat; kompas akan menunjuk arah kiblat dengan derajat.
- Jika perlu, tekan "Kalibrasi Kompas" dan putar perangkat dalam pola 8.

## 7. Dzikir & Tasbih
- Pilih kategori dzikir (setelah sholat, pagi, petang, tasbih, istighfar, sholawat).
- Tekan tombol **+ Tambah** untuk menambah hitungan tasbih.
- Tekan **Reset** untuk mengatur ulang hitungan.
- Hasil tersimpan otomatis ke riwayat per pengguna.

## 8. Kumpulan Doa
- Pilih kategori atau gunakan pencarian.
- Tekan doa untuk melihat detail (Arab, latin, terjemahan, referensi).
- Tekan bintang untuk favorit, atau ikon salin untuk menyalin teks.

## 9. Al-Qur'an & Murottal
- Lihat daftar surah dengan nomor, nama, jumlah ayat, dan jenis.
- Cari surah melalui kotak pencarian.
- Tekan surah untuk memutar audio murottal (play/pause/stop).
- Tandai surah favorit.

## 10. Pengaturan
- Ubah nama, email, dan password pada bagian Profil.
- Atur lokasi dan metode perhitungan sholat.
- Aktifkan/nonaktifkan notifikasi, suara, getaran.
- Ganti tema terang/gelap.
- Lihat informasi aplikasi dan pengembang pada bagian Tentang.

## 11. Keluar
- Tekan **Keluar** pada halaman Pengaturan untuk logout dan kembali ke halaman Masuk.
